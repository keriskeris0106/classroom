# 🏫 교내 특별실 실시간 예약 웹 시스템 (2026학년도 2학기 전용)

2026.8.17.(월) ~ 2027.1.8.(금) 사용을 위한 교내 12개 특별실 실시간 예약 웹사이트입니다.

---

## 🌟 핵심 특징 및 기능

1. **PC 와이드 모니터 최적화 (100% Full Width View)**
   - 한 달 간의 모든 평일(월~금)과 7개 교시 행을 화면 스크롤 최소화하여 직관적으로 확인.
2. **십자선 마우스 호버 (Crosshair Hover)**
   - 셀 마우스 오버 시 가로 교시 행과 세로 날짜 열 전체에 ┼ 형태의 옅은 음영이 표시되어 시선을 유도.
3. **오늘 날짜 자동 강조 (KST 기준)**
   - 대한민국 표준시(KST) 기준 '오늘'에 해당하는 날짜 열에 선명한 테두리와 "TODAY" 뱃지 노출.
4. **자유 텍스트 입력 & 2개 버튼 덮어쓰기 경고**
   - 드롭다운 없이 `+` 빈 셀 클릭 후 즉시 자유 입력 (`예: 3학년, 3-6, 예술강사`).
   - 이미 예약된 셀 클릭 시 경고 팝업에 **딱 2개 버튼** 노출:
     - `[네, 변경하겠습니다]` (수정/삭제 폼 진입)
     - `[아니오, 변경하지 않겠습니다]` (모달 닫기)
5. **디테일한 반복 예약 시스템**
   - 요일 선택 (월/화/수/목/금), 7개 교시 체크박스 다중 선택 (예: 3, 4교시 동시 선택), 시작일 및 기간 지정 후 일괄 등록.
6. **오늘의 특별실 현황 대시보드**
   - 오늘 하루 동안 교내 12개 전 특별실의 예약 상황을 종합 파악할 수 있는 일력 표.
7. **미니 히스토리 (최근 변경 내역)**
   - 실시간으로 예약/수정/삭제 변경 기록을 타임스탬프와 함께 표출.
8. **초깔끔 인쇄 모드 (Print View)**
   - 버튼 하나로 웹 UI 요소를 숨기고 A4 가로/세로 출력 최적화 서식 제공.

## 🔥 파이어베이스 Realtime Database 설정 방법

1. [Firebase Console](https://console.firebase.google.com/)에 접속하여 새 프로젝트를 생성합니다.
2. 프로젝트에 **Realtime Database**를 추가하고 보안 규칙을 설정합니다:
```json
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
```
3. 프로젝트 설정에서 **Web App**을 등록하고 `databaseURL`과 `apiKey`를 복사합니다.
4. 웹사이트 상단의 **`[⚙️ 파이어베이스 연동]`** 버튼을 눌러 정보를 입력하면 전 교사 PC/모바일 접속 시 100% 실시간 공유됩니다.

## 🚀 버셀 (Vercel) 배포 방법

1. [Vercel](https://vercel.com/) 로그인 후 **Add New Project**를 선택합니다.
2. GitHub 리포지토리(`https://github.com/keriskeris0106/classroom.git`)를 선택합니다.
3. Environment Variables에 아래 항목들을 등록(선택)하고 **Deploy**를 누르면 끝입니다!
   - `VITE_FIREBASE_DATABASE_URL`
   - `VITE_FIREBASE_API_KEY`
